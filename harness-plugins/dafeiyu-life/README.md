## 组成

- `index.js`：宿主 SDK、原生工具注册、模型适配、既有会话绑定、后台生命周期。
- `lib/engine.mjs`：常驻分轮探索、时段、暂停、预算耗尽处理、先落盘后关机。
- `lib/store.mjs`：原子落盘账本、原文外发检查、来源卡片、自我札记、总结。
- `lib/policy.mjs`：北京时间、配置校验、文本与公网边界、费用保守预占。
- `lib/budget.mjs`：逐请求结算、日账一致性校验和旧账保守迁移。成功完整回执释放预占差额，未知费用保留；日上限不变。
- `lib/sources.mjs`：公网 HTTPS、DNS/重定向检查、真实 RSS/正文/榜单、授权文本读取。
- `lib/browser.mjs`：调用原有浏览器工具的检查器，保存草稿、账号核对、单次提交许可。
- `lib/migration.mjs`：仅替换标题明确为自由活动的旧自动化，保留其他工作安排。
- `lib/verification.mjs`：固定回声模型与工具验收，不执行外部工具或关机，防止重启重复收费。
- `lib/knowledge.mjs`：全部知识卡片的中英文词语检索，默认过滤私密卡片。
- `lib/trends.mjs`：保留真实时间的热榜样本和跨时间变化，不计算虚假爆款概率。
- `lib/media.mjs`：授权路径检查、SRT/VTT解析、ffprobe成片检查、前60秒音频响度测量；子进程可取消、有超时。
- `lib/health.mjs`：安装版本、工具注册、密钥配置标志和最近验收状态，避免把入口误报为实际成功。

自主循环只获得有限学习工具；能力增长保存为方法与待验证提案，不自动信任并执行网上代码。主会话的终端权限仍由用户及 Harness 管理，本插件不构成操作系统隔离边界。

## 本地可靠性修订 1.4.5-lian.1

2026-10-29 修订，仅改进现有自主活动预算和状态可靠性，不改变 6.66 元自主预算与手动任务费用的区分，也不改变活动时段、自动关机、账号或权限默认值。

- 同一数据目录的预算预占、结算和配置更新现在使用跨进程文件锁。操作先读取最新账本，再检查额度并原子保存，防止两个 Store 实例分别通过旧余额检查或覆盖彼此流水。
- 普通状态保存采用基于读取版本的三方合并。互不相关的字段可以合并，同一字段的相互冲突改动会返回 STATE_CONFLICT，不静默撤销另一窗口的暂停、任务或授权状态。
- 存活进程的锁不会因时间长而被抢占；确认 PID 已退出的锁可以恢复。缺少/损坏 owner、无法确认进程状态、恢复标记残留时停止写入并报告 STATE_LOCKED，需维护者核对，不能猜测后删除。
- 未知费用继续保留预占；互相矛盾的已结算服务回执被拒绝。自由活动的模型输出上限须为正整数。
- 状态冲突使本地调度延后并重读，不用错误状态覆盖其他实例的有效状态。

账本 schema 保持不变。上线时必须停止或重载所有使用同一账本的旧写入者；旧代码不认识新锁，仅复制文件不能使旧进程受约束。应用层锁保护使用本实现的正常写入者，不防御绕过它的其他程序。跨主机共享盘不在本次 Windows 本机验证范围。

回归测试使用合成临时目录、模拟平台回执和独立 Node 子进程，无真实模型调用、社交发送或系统关机。隔离升级目录下可运行：

```powershell
node --import ./test/staged-imports.mjs --test test/*.test.mjs
```

staged-imports 仅用于升级副本与原安装目录的布局差异，不改变生产插件的导入路径。关机测试显式开启测试配置，生产默认仍为关闭。

故障注入补充：本次新建锁的 owner 写入失败会清理自有锁；写入、fsync 或 rename 失败保留旧文件并清理本次 JSON 临时文件。其他进程留下且来源不明的锁仍不会被猜测删除。
