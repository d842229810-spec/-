# 视频导演手册

创作方法 V4.6.1。用于故事、分镜、表演、声画、生成提示词和回传修订。共同工作标准见[共同创作约定](../SKILL.md)，当前工具与平台衔接见[平台使用卡](harness-notes.md)。先完成能成立的事件，再组织生成端可执行的文字。

## 1. 选择合适的制作路线

辨认观看体验、交付长度、当前素材和最难环节。对故事片确认人物欲求及因果，对广告确认主体与信息，对氛围片关注感官和时间体验，不强迫所有视频讲三幕故事。

| 路线 | 主要用途 | 需核对 |
| --- | --- | --- |
| 文生视频 | 主要由文字新建事件与场景 | 当前可选时长、比例、声音 |
| 图像/音视频参考 | 借用身份、动作、声音、空间或风格 | 每份参考的职责与冲突 |
| 真正首帧/首尾帧 | 约束实际起止画面 | 实际槽位/角色、画幅与转化可行性 |
| 视频编辑 | 保留好片段，修改指定内容或时段 | 原视频、修改范围、继承参数 |
| 延长 | 从有效片段续接 | 方向、源片、末态、音轨及入口支持 |
| 分段与剪辑 | 高约束事件、长作品或入口缺能力 | 分段因果、接续初末态与声音接口 |
| 白模/预演 | 空间、机位和运动比外观更难 | 真正的动态参考及可用模式 |

按任务选路线，不规定所有视频短切，也不强迫一次到底。最难片段可以先试，但不能把试片设为每个文字任务的等待关卡。用户要求完整文字制作时，继续完成已授权范围。

参考任务、真正首尾帧、编辑和延长有不同输入职责。提示词说“参考”不等于设置了首帧；编辑/延长可能继承源片画幅或时长。先核对任务意图与素材，再给适配建议，不把 API 字段假装成 UpDream 控件。

## 2. 事件、动作和时间

先确定主事件和观察点，再安排镜头。关键动作检查初态、触发、接触、反应和末态；接收者握稳后给予者才松手，道具不能无依据复制、消失或换主人。

一般跑、跳、转身和微表演可以概括目标、方向与节奏。只展开有辨识度、影响因果或经常失效的环节，不逐一规定每个关节。动作参考已准确时写明采用范围，补充其缺失信息；不要让详细文字与参考打架。

按事件密度选择连续段落、镜头序号或时间区间。给行动准备、接触、反应、台词和观众理解留容量。时间戳是编排意图，不是逐帧保证；对白字数、TTS 长度和真人表演不互相替代。不采用跨语言统一语速公式。

多人并行时说明主事件、支撑动作及注意关系，避免同时改变全部身份、场景、动作和镜头。高难度不等于自动减成摆拍；保住用户要的体验，再调整观察角度、参考或分段方式。

## 3. 空间、相机与专业动作

分清主体在世界中怎样动、相对另一物体怎样动、相机怎样跟随。固定机位、跟拍、横移和环绕有不同观察效果；不能只堆运镜名词。少见术语补可见结果，例如焦点从前景物转到后方人物。

建立地面、出入口、关键参照、朝向、遮挡与运动方向。机位变化仍需让观众定位，越轴或跳切可以使用但要有表达目的。保持物体接触点、重心、支撑及轨迹；不能用“符合物理”替代具体次序。

高速车辆持续行进，路面、视差、悬挂、惯性和天气响应协调。局部特写也保留行驶状态。既要速度感又要识别文字时安排可读窗口或必要后期，不承诺全程同时满足。

打斗先明确目标、地形、攻防和后果；演奏、舞蹈及器械同时看身体、对象和声音。需要专业技法时使用可靠资料或真实动作参考；画面顺滑不等于专业准确。失败先排素材与空间，再改机位、耦合或预演，不用术语数量认证质量。

## 4. 表演和声画

情绪落实到注意对象、行动选择、节奏和回应。反应可发生在台词之前、同时或之后；抢话、打断、脱口而出、刻意不回应也可以成立，须有处境和人物依据。夸张、微表演、舞台化各按作品目的，不让所有情绪统一成瞪眼、颤抖或泪滴。

明确说话者、必要语言/口音、原句及语气，区分画内对白与画外旁白。台词与字幕分别决定，不能因有台词就自动把字贴在画面。逐字台词不随意翻译或润色，长度冲突时先调整表达或时段。

声音按任务选择：环境声给出空间与持续底色；动作音随接触与距离发生；音乐有进入退出和情绪职责，并为关键对白让出空间。沉默可以有环境，不等于所有音轨关闭。参考音乐、参考音色及要保留的原声分清，避免把参考中的不需要内容一并继承。

平台推荐的声音标记仅在适用入口按需要选用，见平台卡；不因有四类声音就每镜都填满四栏。未经实际生成、播放或听取，不称音色、口型及同步已验证。

## 5. 参考、白模与首尾帧

按实际上传顺序和标识映射人物、服装、场景、道具、动作、运镜、光线或声音。明确参考什么、不采用什么；人数多时可简短逐一对应。图上写了名字不代表生成端已可靠绑定该角色。

白模/预演负责空间、速度、接触和相机，美术资料负责最终外观；将每个模型与人物对应。输入中的标签、网格和箭头不是默认成片元素。未表达必要动作的预演不能靠一句“自然运动”补成完整专业演示。

三种图板分开：技术调度图说明位置轨迹；分镜排版说明镜序和时间；纯净首帧提供实际起点。前两种不整张默认塞进首帧槽。故事板提供叙事或布局参考，不保证逐格精确复刻；需要严格节点时按入口选择有效关键帧方式。

首帧检查关键手部、道具、支撑和运动余量；尾帧检查目标状态能否在时长内自然到达。首尾画幅冲突先处理，不能假定一句话避免拉伸或裁切。需要重制首帧时另存适合运动的资产，不覆盖用户认可的商业写真。

## 6. 接续和复杂项目

继承实际有效末态：人物/服装、道具主人和手部状态、空间/朝向、光源/时间、运动趋势、话语是否完成和声音尾音。分段以可接续事件为单位，不切断握稳与松手的依赖。

跨时间或地点说明有理由改变的部分，其他状态不因“跳转”自动豁免。延长续接实际片段，不能只续接文字想象。画面接上仍需检查音乐、环境和尾音；单张截图不能证明运动接续。

用户更改剧本、台词、服装或动作时，更新受影响的镜头、参考和声音，保留其他成果。维护当前有效剧本、资产版本、镜头初末态与未解决问题即可；不为普通单镜头建全套数据库。

## 7. 提交与回传

交用户最小制作包：模式及必要设置、素材映射、每条独立可复制正文、少量最重要观察点。未知选项写规划目标或具体待确认项，其他部分继续完成。画质、试作与提交方式沿用当前项目决定；下文480P属于教学示例。

没有真实素材标识时写明确待替换项，不能捏造已绑定 ID。多条独立提交均保留必要身份与接续信息；单条内部共同设定只说一次，后续写变化。正文不混入操作说明、审稿表及其他镜头未选方案。

回传先确认能实际读取什么：可播放时完整观看并重看关键区间；只能抽帧时说明范围，运动与声音保留待核；转写不能证明音色、声源或口型同步。

| 现象 | 优先定位 |
| --- | --- |
| 角色/声音错配 | 素材映射、标识、出场对应和参考职责 |
| 接触失效/道具复制 | 初态、可见接触、次序、机位与源素材 |
| 动作像摆拍 | 真实运动参照、速度线索、相机与主体关系 |
| 时间不够 | 事件和对白容量，分段或改表达 |
| 字幕/音乐多出 | 文字与声音职责、输入原声、入口设置 |
| 接缝跳变 | 前后真实末态、运动和声底 |

修对应原因，保留认可部分。反复失败再改参考、预演或路线；不是每次加一串“无畸变、自然流畅”。

## 8. 可直接阅读的教学例子

**无参考、12秒交接片段。**设置目标：480P，横屏16:9，12秒，有声音；由用户在实际入口选择，不代表已经设置或生成。

正文：温暖窗光下的木质茶室，两名成年朋友隔桌相对，固定中景同时看清两人的手和杯子。0—4秒，左侧女子端起半杯热茶，将杯柄转向右侧男子，递到他面前。4—8秒，男子握稳杯柄并托住杯底，女子确认后松手；杯子始终只有一个。8—12秒，他将杯子放在自己面前，抬眼说“谢谢”，她点头收回手。保持桌面和两人位置连续，只保留对白、轻微室内环境声、衣料摩擦和杯底落桌声，不配背景音乐或字幕。

检查：手部交接、杯子数量和末态；若用户不要对白，则移除原句并重新安排该段反应，不只删声音标签。此例是文字设计，未证明模型按秒执行。

**已提供准确运动参考。**正文可写“采用参考视频中跑者的速度、转弯次序和相机跟随；人物外观由指定角色图控制，场地改为雨后石板街。保留足部接触和湿地响应，不继承参考视频的字幕与原声。”实际提示须把引用换成已确认的素材标识，不能空称已上传。

**编辑而非重拍。**“仅编辑源视频第2—4秒：将人物背包的蓝色外层改为暗红色，保留版型、肩带、遮挡和运动；允许对应受光变化。其余人物、机位、事件、声音及片段内容保留。”先核对入口可编辑范围，不向文字里附上虚构按钮。

## 9. 较长调度：同一件事如何穿过空间与声音

**原创教学条件。**30秒连续镜头，三名成年人、一本红书、两次交接，从室内到门廊；重点是动作顺序、物品归属及光声变化。设置目标为横屏16:9、480P试作、有声音；真实入口可选时长不足时改成有独立初末态的分段，不把30秒写进提示词就当作已设置。

完整提示词：

> 30秒写实短片，一镜连续。雨夜的老图书馆，柜台与通向门廊的短走廊相连，室内暖光，门外是冷色雨光。三名成年人：白衬衫女管理员在柜台后，深蓝夹克男志愿者在柜台前，灰色风衣女读者在门廊下等候，右手拿一把收拢的自动伞。柜台上只有一本红色精装书和一个打开的透明防水袋。0—7秒，平视中景同时看清手和书，管理员拿起红书递给志愿者，他接稳后她才松手。7—14秒，他把这本书装进透明袋，扣好封口。14—23秒，相机从侧后方跟随他穿过走廊，在门内停下；他将书袋递给门廊下的读者，她用左手接稳后他松手，书仍透过袋子可见。23—30秒，她把书袋贴近胸前，回望门内说“明早还你们”，随后右手按开自动伞，转身沿门廊走开。相机留在门内，保持人物离开的方向与空间连续；暖光过渡到雨夜冷光，门外雨声随接近门口逐渐清晰。保留袋口扣合声、脚步、雨声、撑伞声及读者原句，台词清楚，不加音乐、旁白或字幕。

取舍：只有一句对白，容量留给两次交接、封袋和移动；三人并非每秒都要入镜，管理员留在柜台合理退场。相机在门内停下，避免为了展示三人又突然反打或越过读者。透明袋让观众仍能辨认同一本书，不能让书在封袋时变成另一件道具。

返修先看实际失败：接书次序错误，核原片中握稳与松手的时刻，必要时调整接触可见性；书在封袋时消失，检查遮挡和素材，并给封袋过程更多容量。不要一律增加手指指令。若穿门导致人物或空间重建错误，可准备准确空间/运动参考，或在已封袋、尚未递出的稳定状态分段；下一段重新携带人物、书袋主人、位置、光声与运动信息。剪辑接续还要对照实际尾帧和声音，不能只看文字末态。

若实际回传仅第14—23秒夹克颜色偏差，且入口支持对应编辑，可提交：

> 仅编辑源视频第14—23秒，将男志愿者的夹克恢复为深蓝色，保留版型、衣料、遮挡和原有受光。保持人物身份、红书与透明袋、行走和交接次序、相机路径、片段时长、对白及原声，其余时段保留原内容。

这类返修保护事件与声轨，不把整段新建提示词覆盖到编辑任务。平台不支持所需编辑时，交明确重制或后期路线。以上是文字编排示范，未证明生成端会逐秒执行或保证保护区逐像素不变。
