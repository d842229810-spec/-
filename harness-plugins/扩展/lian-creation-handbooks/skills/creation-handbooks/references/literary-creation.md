# 文学创作手册

创作方法 V4.6.1。用于小说、短篇、对白、剧本、修订与跨媒介改编。共同工作及提示词标准见[共同创作约定](../SKILL.md)。按当前文体选择章节，示例用于解释方法，不是用户认可样稿或固定风格配方。

## 1. 先决定这次值得经历什么

辨认形式、题材、目标体验和读者语境。幻想可以写关系、悬疑或日常；严肃作品可以轻松，喜剧也可以有真实代价。不要仅凭题材名套一种情节。构思时提出彼此不同的事件机制，而不是只换名字、职业和地点。

完整作品需要可指认的看点：选择造成什么、读者为什么关心、信息如何改变理解，或者语言与观察本身怎样产生体验。安静作品允许很小的变化；诗与散文无需假造冲突。用户已给足条件时主动设计未锁定部分，关键缺口才提问。

小稿直接写；长篇或复杂叙事按需要规划整体、章和场景。大纲应写事件、选择及结果，避免“深化关系”“迎来转折”等空标签。大纲有用才展开，不能把写正文变成永无止境的前期准备。

## 2. 人物、视点和信息

重要人物有自己的欲求、能力边界、关系经验与当下策略。区分人物知道、猜测、误以为和故意隐瞒的内容，以及读者何时获得它们。改变视点要有观察或叙事作用，不能只为在悬疑中藏掉当前人物必然想到的事实。

人物声音来自怎样请求、拒绝、纠正、转移话题、承认和保持沉默；职业和文化语境也影响表达。口头禅只是可能的细节。检查关键选择和整场语体，不要求每句普通问候都能猜中姓名。

原作事实、用户改编与暂定创作分开。已有关系不擅自降级或重置。涉及原作、历史、法律、科学和国别生活细节时按实际资料核对；未证实的设定不冒称官设或史实。调查解决当前问题，不假装掌握全部国家和学科。

叙述者与人物可以有不同可靠性。人物谎言不自动成为世界事实，反讽、自由间接引语和不可靠叙事须让阅读方式成立，而非为漏洞临时找解释。

## 3. 场景和中文交流

场景中有人在做事、注意某件事、试图得到回应或重新理解处境。检查初态、触发、尝试、对方处理及结果，不强制每场大转折。动作和物件承担作用，避免平均罗列五种感官。

对白先处理对方刚说的话、正在做的事和共同知识。玩笑、偏答、明知故问也可以有策略。只为给读者说明资料的台词需要调整，但职业、教学、侦查等情境允许有目的的说明。

把疑难句放回说话距离、关系、动作和情绪里试说。没有音频只称文字试读。不能把“去 AI 味”做成删长句、加语气词或禁用某些词；修改指代、搭配、信息负荷和交流目的。诗性、舞台化与日常口语采用不同尺度。

可用三种检查定位问题：上一句换了意思，回应是否也应改变；关键行动者互换，人物选择是否损失；撤去“温柔、甜蜜、悲壮”等赞美，正文是否仍给出体验。检查有语境，不机械判错。

## 4. 群像、同行和多线

先确定共同目标和各人的个人目标。谁掌握信息、能作选择、愿意付代价，会改变队伍的行动。伙伴可以暂时缺席或退到次要位置，不能长期只负责接话、解释和赞美主角。

分配作用看因果，不按人数平均戏份。关键时刻可以由一个人完成动作，但此前的资源、判断或关系须来自确有作用的选择；也允许个人失败改变下一步。视角轮换应增加信息或情感，避免重讲一遍同一事件。

同行的日常利用工作方式、资源、疲劳、秘密和生活习惯的差异。每个章节不必全员出场；一段交流不必每人接一轮。人物结盟和分歧要影响后续，不每章回到初始关系。

主线与支线相互产生条件、阻力或认识，不以“插一段恋爱、再插一段搞笑”机械拼接。支线可以暂时独立，但其篇幅和回收应符合读者得到的承诺。

## 5. 喜剧与关系进展

幽默可来自预期落差、地位变化、处境、语言视角、重复中的变化或认真追求不合适的方法。笑点须属于这个说话者和情境；不让所有人都成为同一种机灵人。

铺垫使读者理解预期，变化改变结果，后果继续存在。允许纯粹轻松的片段，不要求每句推进主线；但长期绕开已迫近的危险会消解故事。严肃场面里的幽默可以减压，同时保留人物的处境与代价。笑点是否成立需阅读反馈，不能由作者宣布。

关系先看相处阶段及双方正在注意什么。亲近可以由偏爱、记忆、主动选择、信任和回应形成；照顾不必夺走对方的主动权。稳定关系允许直说、舒服的沉默和小习惯，不强制误会、吃醋、嘴硬或每场升级。

“她脸红了”“他牵住她”可以有效，但手势数量不等于情感。说明这一次互动为什么特别，对方如何注意或改变行为；也允许观众先看懂，不能整篇让另一人没有自己的愿望。

## 6. 类型方法与适用边界

| 方向 | 主要设计问题 | 常见返工点 |
| --- | --- | --- |
| 现实/职业 | 利益、职责、程序和人情怎样共同影响选择 | 工作过程失真、所有人只讲观点 |
| 幻想/冒险/轻小说 | 世界规则、代价、探索、队伍与成长怎样产生事件 | 临时加能力解围、伙伴背景板、梗盖过故事 |
| 科幻/思辨 | 假设具体改变了什么生活和决定 | 只换科技名词、解释没有戏剧作用 |
| 悬疑/推理 | 线索、可见信息、替代解释和揭示次序 | 单一细节直接定罪、故意藏视点信息 |
| 惊悚/恐怖 | 未知、威胁、失控和安全感怎样变化 | 靠连续惊吓、越描写越失去想象空间 |
| 历史/武侠 | 时代制度、身体行动、义务与选择 | 现代口号换古词、招式没有地形与后果 |
| 喜剧/讽刺 | 预期、人物立场和现实代价 | 为笑点降智、所有角色统一吐槽 |
| 爱情/家庭/友情 | 关系如何通过行动被理解或改变 | 重复误会、情感由旁白代宣布 |
| 诗/散文/实验 | 声音、意象、观察、结构和阅读过程 | 强塞转折、意象彼此无关联 |

这些是选用角度，不是必须叠加的清单。跨国别创作先确定年代、阶层、地区和语言；必要时核对称呼、制度、日常物件与语体，避免国民性标签。翻译与本地化保留关系、双关功能及声音，不能只逐词替换。

## 7. 长篇、连载与更正

分清连续长故事、可独立阅读的单元与群像系列。连续故事维护承诺、进展和兑现；单元故事保留稳定吸引点并引入变化；不强制每章同一种悬念结尾。段落承担事件、观察、关系、铺垫等不同作用，不能把所有铺垫视为水字数。

长项目按需维护四层：世界与锁定事实；卷内事件、关系和开放伏笔；章内目标、选择和结果；最近场景的时地、所知和未完行动。层级是定位方法，不要求四个数据库。人物能力、时间、伤势、道具、财物和知情状态在相关时核对。

伏笔区分计划、已写入、角色已知、读者可知和实际回收。回收前重新读取有关原文，不能靠摘要虚构曾经铺垫。作者临时决定不自动晋升为正文事实。

用户更正先定位影响范围，例如一人从“已知秘密”改为“不知”，后续试探、推理和揭示均要重查。保留不受影响的文字，更新有效状态及下一步。跨会话续接交目标、有效正文位置、关键事实、开放问题和下一场，不宣称无限记忆。

## 8. 改编为图像和视频

标出人物原话、可见行动、叙述判断和内心。找出读者理解当前选择所需的信息；选择画面、表演、声音、旁白或字幕承载，不把全部内心塞进台词，也不机械删掉旁白。

一幅图片选一个有意义的瞬间，必要时才做明确的多格；视频按事件组织观察点和时间。场景可以合并，表达方式可以变化，但保住用户锁定的因果、人物主动性和体验。新增桥段作为改编选择，不冒称原作。

技术调度图、分镜排版和纯净首帧职责分开；正式资产和镜头依据当前有效剧本。若关键动机或因果尚不成立，先修文本，再完成依赖它的正式制作；用户要求看草稿时可清楚展示未定内容，不用制作数量冒充质量。

## 9. 原创教学片段

以下均为方法示例，不能据此宣称已验证持续写作能力。

**安静的熟悉关系。**临行前，岑宁试着把相机塞进已经扣不上的包。许澄把车票放到桌边：“这个包我背。你的镜头别压下面。”岑宁看了眼他的手腕，把自己的行李往回拉了一点：“那你拿相机，我背衣服。昨天搬箱子还没缓过来吧？”许澄没有再抢，替她把肩带放长两格。她背起来走了两步，回头等他锁门。

作用：两人各有判断和回应，照顾没有成为单方面表演；安静不需要关系危机。若移除手腕和搬箱子的依据，后一句的关心会变空。此种语气不自动适用于初识、敌对或夸张喜剧。

**幻想同行与喜剧。**天黑前，三人得把药送过山口。雨刚停，药师阿禾蹲在石棚里重煎途中打翻的那一剂。沈砚把仅剩的干柴往炉边推，术师小满伸手拦住：“留一根。到隘口还要点信号火。”沈砚看了眼湿透的靴子，把脚从炉旁收回来。小满用两个指头托起药碗，掌心的红光一点点变亮。阿禾闻到焦味，立刻接过碗：“够了。”三人同时低头——沈砚刚拧干的袜子搭在碗架上，边沿卷起一道黑。沈砚把它取下来，想了想，塞回包里：“还能当引火的。”小满张嘴，阿禾把装好的药递给沈砚，转头对小满说：“你看路。下次闻见焦味先告诉我。”出棚时，沈砚把那根干柴扎在包外，将药包揣进怀里。

作用：送药和信号火决定资源选择；药师、护卫、术师分别影响结果，笑点留下实际损失。要继续写，须继承干柴、烧坏袜子和时间，不把它们下一场重置。用户若不接受该类生活喜剧，应换机制，不能仅提高吐槽密度。

**职业信息可以完整。**“今天能给客户吗？”“图能给，价格表还不能。采购刚换了供应商，我得核一遍税点。”“那我先发图，报价明早补。你核完给我标一下改动，别让我从头找。”后一人没有只说“收到”，而是据新信息调整交付。长句承载真实条件，不必为自然感全部拆碎。

**悬疑要保留替代解释。**仓库门口有一串湿脚印，值班员的鞋却干着。侦查者先问鞋有没有换过，再核雨停时间、入口和谁擦过地。脚印能改变调查方向，不能单独证明撒谎；后续揭示须使用读者确实得到过的线索。

**心理转为镜头。**原文：“她没有再问去年的事，才发现自己一直握着那张旧车票。”改编可让车票先有必要来历，再拍她放松手指，把它夹回书里，继续眼前的谈话。也可使用恰当旁白。不能只拍无来源的纸片，再在提示词里宣布“彻底释怀”。

## 10. 复杂机制：怎样取舍，怎样返修

以下是原创教学设计，重点是信息和后果，不能当作所有题材的统一节拍。

**悬疑：让线索改变调查，而非替作者宣布答案。**设定：停电期间，档案室的一封信失踪。门外机械计数器在停电前被核记为41，恢复照明后、调查者尚未开门检查时已显示42；保管员却说停电后无人开门。读者此前见过正常开门会使它加一，管理员也说过当晚没有维修。第一种解释是保管员撒谎，第二种是有人绕过他开门，第三种是计数器本身故障。

推进不能只写“侦探看出破绽”：先核计数器的工作方式与异常记录，再查钥匙与备用入口；有人承认开过门，但称只取外套，调查由“有没有开门”转向“开门者是否取信”。保管员的否认也可能出于替他人隐瞒，而非偷信。最后答案须靠已经出现的时间、接触机会及独立线索区分这些解释，不能临时添一个从未提及的监控。

若用开门者视点，他当时明确知道自己开过门，不能靠删除这个念头制造同一种悬疑。可换为不知道门开过的调查者视点；也可让读者早知开门，悬念改为他在保护谁。返修定位：线索过度定罪，补验证和替代解释；视点作弊，调整可见信息及谜题；结尾无前因，回写必要铺垫并重查揭示次序，而非只改结尾措辞。

**群像：让支线带回条件，也带回代价。**冒险队要在涨潮前把药送到河对岸，旧桥已经朽坏。药师坚持药不能沾水；护卫检查桥旁两岸固定的旧渡索；斥候去下游找泊船；术师的体力只够短时托桥或发出一次接头信号，无法支持全队携药过桥。四人的贡献无需同场轮流发言。斥候找到的船少一支桨，护卫在确认渡索可用后，改用沿索牵引的办法；药师用防水布包药箱，再将外衣垫在箱下，免得粗糙船板刮破防水层，牺牲保暖；术师留力在对岸发信号，而非再次凭空加法术解围。

喜剧可以来自斥候先把船描述得十分体面，转弯才露出缺桨的一侧；同伴的回应要据此改变办法。不能笑完就让船自行快航。下一场仍要继承湿衣、缺桨、剩余体力及谁知道信号已发出。若同伴只剩吐槽，改的是任务分工与选择后果；若支线像插播，重建它对主线的资源、信息或关系作用。没有必要让每个人都在每场做同样大的贡献。

**文本转影视：保住观众理解选择的依据。**上述群像若改成短片，不能只把四人拍成各做一件事，再用旁白说“他们配合默契”。先让观众看见药师护住药箱、护卫试出桥板松动并转而检查渡索，再让缺桨的船进入视野，沿索牵引的选择才有来历。篇幅不够时可合并人物职责或缩减支线，但用户锁定的角色作用不能静默删除；删去斥候支线后，也应重做船的来源，不能让它无因出现。

## 11. 审阅与返修

| 项 | 实际核对 | 发现问题先改哪里 |
| --- | --- | --- |
| Q1 需求与体验 | 去掉标签仍能读到目标体验，范围正确 | 需求、事件选择 |
| Q2 人物与选择 | 欲求、知识、策略和关系支撑重要行动 | 人物与信息分布 |
| Q3 因果与动机 | 前后行动有条件，替代解释被合理处理 | 场景与事件 |
| Q4 真实交流 | 回应处理了对方的信息、动作或策略 | 对话过程 |
| Q5 中文与声音 | 措辞、指代、语体适合当前说话者 | 具体语言 |
| Q6 情感与关系 | 情绪有依据，对方有回应或有意未察觉 | 互动与视点 |
| Q7 发展与兑现 | 看点依赖前文，重复产生变化 | 结构与伏笔 |
| Q8 节奏与表达 | 篇幅及动作/对白/观看容量适合媒介 | 删减、扩展与表达 |

完整叙事稿检查各相关项，关键不成立就修；证据不足不算通过。审稿任务给具体位置、短引文、问题与改法；普通成品不默认附八项表。没有独立评审就称作者自审，不把用户未评价当认可。

返修按需求→人物/信息→因果→交流→语言→媒介定位。大纲错了不靠润色解决，孤立弱句也不需要推倒整篇。两轮同类失败重看事件或表达机制。保留用户认可的成果，重查实质修改影响的下游。
