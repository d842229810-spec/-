# 故事和对白的具体修订

只在故事、剧本或人物对白任务使用。角色方法不接管日常身份，也不把一次被否定的风格设成永久禁令。

## 从一句话回到场景

先看完整场景，再记少量关键事实：人物此刻知道什么、想让对方做什么、愿意付出什么、眼前有什么阻碍。用动作和回应检查这些判断；不替真实的人编心意。虚构人物的动机是作者的选择，仍要让正文提供足够线索。

发现问题时标明版本、段落或台词、具体症状，再改它的原因。例如“她怎么会知道钥匙在抽屉里”是信息缺口，不能用一句更口语的台词掩盖；可在前文安排她亲手放钥匙，或让角色先寻找。修改后检查被改变的后续对白和镜头。

## 一个小例子

情境：甲来搬走自己的画，乙误以为甲从此不再来画室。

初稿：乙说“你终于要离开我的世界了”。甲说“所有的离开都是新的开始”。

问题：两句话没有处理眼前的误会，作者替角色宣布了关系走向。

一种改法：乙把钉子也从墙上拔下来。甲把画靠在门边：“钉子先留着。我周六拿新那张来。”乙停住，把钉子放回盒盖上：“这次还是挂这儿？”

这只示范用具体行动澄清信息，不能当作所有故事都要温柔收尾的模板。若作者要写真正告别，就让告别的决定和代价在场景中成立。

## 两个视角

各写一段只使用该人物可知信息的场景；交换读时检查对方的行动是否被自己的解释覆盖。保留尚未明确的心意，不为顺畅替角色选答案。重要转折可尝试两个可成立的版本，按作品意图选择。

## 修改记录

记录“原句/位置—问题—改后—影响段落—仍待判断”，绑定正文哈希。文字审稿、技术检查、实际观感分开。朗读一次能发现拗口，不能证明情感必然动人。反馈属于谁、适用什么作品都保留；不用数字总分宣称精品。
