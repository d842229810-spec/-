# 视觉创作手册

创作方法 V4.6.1。图片的设计、参考、编辑和提示词方法。共同成稿标准见[共同创作约定](../SKILL.md)，ChatGPT/Grok 的真实入口差异见[平台使用卡](harness-notes.md)。本手册不用字段拼接代替美术设计。

## 1. 从用途形成画面

先知道作品用在哪里、给谁看、要呈现什么。角色写真、叙事插画、商品广告、海报、信息图、界面素材和视频首帧需要不同设计；不要给每张图统一加浅景深、粒子和电影光。

提取主体身份、数量、精确字串、构图范围、动作/关系、媒介、画幅、参考及保护项。区分锁定要求、主要审美目标和可选装饰。先选视觉中心，再安排轮廓、主次、观看路径、明暗、色彩面积和前中后景。复杂任务可比较少量不同构图，不把参数决定全部丢给用户。

先缩小看中心和轮廓，再按正常大小看空间、动作和文字，最后放大看身份、材质与边缘。细节多不等于层次好。审美偏好可以强烈、夸张或极简，按本作决定，不把某一种“高级感”固定为默认。

## 2. 空间、数量与冲突

说明谁在什么位置、面对哪里、看向谁、接触什么，谁遮住谁。多人属性逐一对应；物体数量与所有权分别核对。画面左/右、人物自身左/右、镜面中的方向分清。改变机位后重新确认，不能让“左手”同时指两种参照。

人体支撑、手指抓握、衣物覆盖、影子和反射要相互兼容。草图可辅助布局，但不宣称像素级定位。透视、镜面、玻璃和透明物体按实际可见关系核对，不能用“物理正确”一句话包办。

| 冲突 | 处理 |
| --- | --- |
| 全身与紧脸特写 | 保住用户锁定入镜范围，选择景别或经允许拆为不同作品 |
| 复杂服装与姿态遮挡 | 调姿态/角度让关键结构可读，不能偷偷改服装 |
| 单主体与独立道具数量 | 确认“只要主体”是否也排除必要道具；不机械全删 |
| 透明背景与场景/阴影 | 分清要保留的半透明边缘、接触阴影和背景装饰 |
| 高速模糊与文字清晰 | 设计短清晰窗口、角度或必要后期，不能同时许诺所有区域清晰 |
| 局部改光与完全不动阴影 | 识别自然联动与锁定范围，按用户目标提出可行修改 |

## 3. 角色资料与精细视觉锚点

先确定角色、服装版本、参考出处及用户改编范围。实际看见、可靠文字说明、创作选择和未看清部分分开。不凭印象补背面结构，不把不同皮肤/版本的配饰混成“原版”。必要时查角色官方素材；没有查到就保持具体未确认项。

按需要提取以下信息，不要求全部进入最终提示词：

| 层次 | 提取内容 |
| --- | --- |
| 整体辨识 | 发型体积、剪影、主要色块、非对称结构和标志配件 |
| 服装结构 | 内外层、领口、肩袖、腰部收束、开口、下摆及覆盖关系 |
| 连接与装饰 | 扣件、绳结、金属件、刺绣和悬挂物的实际附着位置 |
| 材质 | 厚薄、织纹、褶皱、张力、透光和反射的区别 |
| 表演 | 视线对象、眉眼/嘴部状态、重心和手势所表达的态度 |
| 系列固定项 | 已认可脸、比例、发型、服装版本、配件和颜色分区 |
| 本次变化 | 姿态、表情、场地、机位、光线及授权改造 |

挑出决定当前图辨识度的锚点，优先保证轮廓和结构，再安排可读的细节。角度看不到的装饰无需强行展现；用户要设计背面时，可明确作为原创设计，而非编造官设。

真人 Cosplay 以成年扮演者、专业假发、实体服饰、可信场地和表演建立摄影感。将二维设计转为可穿的裁片、接缝、支撑与重量，保留角色关键轮廓。面部、身形和服装按用户目标协调，不让重复的外貌描述吞掉身份信息。

## 4. 材质、光线与媒介

光写清来源、方向、软硬和作用区域；可由主光、环境光及必要轮廓光构成，不要求每图三点布光。皮肤有细微变化，织物有厚度和受力，金属反射环境，薄纱会透光；同一种“亮”不能代替所有表面差异。

相机高度、距离、景别、视角和景深服务人物气质及空间阅读。85mm 等是效果线索，不保证精确光学模拟，也不是所有人像的必要条件。需要服饰或环境清楚时，不能盲目要求极浅景深。

| 媒介 | 应有的制作特征 |
| --- | --- |
| 摄影/商业写真 | 可信透视、肤质、服装工艺、表演与受控光线 |
| 动漫/漫画 | 线条、色块、形体概括、表情与画面节奏 |
| 水墨/水彩 | 笔触、干湿/透明层、纸感、墨色与留白 |
| 油画/厚涂 | 色层、笔触、边缘、明度组织和体积 |
| 低模/风格 CG | 形体简化、材质体系与渲染意图 |
| 信息图/平面设计 | 层级、网格、文字、符号、对齐与可读性 |

混合媒介按主体说明：二维人物保留线色，真实动物保留毛发，商品保留实物几何；统一空间、受光和接触。全局“写实”不能误覆盖所有主体，除非用户要整体转换。

## 5. 参考、商品与连续资产

实际查看参考后，为每份指定身份、服装、姿态、场景、布局、材料或风格职责。按用户锁定项和有效母版排优先级；姿势图不覆盖服装，风格图不复制其人物，动作参考不改变商品。

参考互相矛盾时分工、删无关素材或准备更合适的参考，不要求“所有方面融合”。准确参考可以代替冗长复述，但关键变化和保护项仍需说明。上传、生成端绑定及实际采用是不同事实，不因文字提到就称完成绑定。

商品按需要核对实际款式、尺寸比例、瓶盖/接口、包装、颜色、Logo/字串及数量。不能靠美术改造变成另一款；成分、功能、认证和效果须有资料，不由创作补造。

母版必须是实际认可的作品。角色主图、商业主图和视频首帧可以分别保存，不为运动余量覆盖已认可写真。失败分支不自动升为最新有效版本；明显身份漂移优先回到认可母版。

## 6. 编辑、文字与透明资产

编辑明确原图、修改对象/范围、要改成什么、保护项及允许的自然联动。先写变化，再简短保留；不把完整新建描述当一次重拍。连续修改每轮与有效基准对照，不只与上一张失败图比较。

有局部编辑工具时按范围使用；没有时选择真实可用的重绘、合成或后期路线。提示词不能保证未改区域逐像素相同。强保护任务应检查原文件，必要时将认可修改合成回原图，并如实说明。

画面字串按用户要求逐字保留，标明其位置、层级和字体方向；说明文字与要渲染的文字分开。海报或信息图先确认事实、数据和阅读顺序，不靠写出很多术语制造信息密度。中文错字逐字检查，模型不可靠时可交无字底图及明确后期排版方案，不能称文字已经准确。

透明背景要求在当前工具支持的设置和正文中正确传递。查看实际文件的 alpha（透明通道）、发丝/玻璃/镂空及边缘，棋盘格不等于透明。输出格式、尺寸与压缩核对真实产物，不把规划值当文件属性。

## 7. 提示词交付与例子

按任务组织主体/用途、构图/动作、场地、光色/材料、必要文字、参考及保护项。复杂图少量分区，简单图一段；不重复共同标准，不默认附整套禁词或多份同内容版本。给用户一份可直接复制正文，必要操作另列。

**原创角色服饰摄影：**竖屏9:16，单人至膝构图。一名30岁女性专业 Coser 站在木质庭阁窗边，墨绿色长发、细红框眼镜，单手轻扶镜腿并看向镜头。穿原创鹤意服装：白色立领外层覆盖黑色贴身内层，腰侧系青绿色薄纱，金色扣件固定在领口与腰带，保留清楚的叠穿和悬挂关系。柔和侧窗光照出自然肤质、白布织纹和薄纱透光，金属反射与织物光泽有区别；背景适度虚化，脸、眼镜及服装主要结构清晰。

说明：这是原创服装示例，不是某角色官设。实际任务按参考重建结构，不套用同一窗光和景别。

**多主体对应：**横幅插画，画面左侧穿白色外套的成年女子拿着红伞，右侧穿深蓝外套的成年男子抱着黄色书，两人在路灯下相向交谈。人物与各自物品清楚分离，红伞不遮住两人的脸，湿路面反射路灯的暖光。

**局部编辑：**只把原图人物左肩上的银色徽章改为相同形状的哑光金色徽章，保留其位置、大小、固定方式和局部遮挡。保留人物身份、姿态、服装其他部分、镜头、构图及背景；只允许徽章受光和紧邻反射作必要联动。

## 8. 高约束成稿：条件冲突时怎样保住重点

**示范任务。**原创“鹤羽使者”真人服饰写真，锁定黑白青绿层次、左肩独立肩披、三根腰侧红绳和单手扶镜；要求看清服装主要结构，也要有人物气质。这里先选到膝构图与适度景深，不同时追求脸部大特写、全身和极浅景深。金属件、绳结只写关键位置，未露出的背部装饰不强行塞进画面。

完整提示词：

> 竖屏9:16，真人商业服饰摄影，单人到膝构图。一名30岁成年女性 Coser 扮演原创鹤羽使者：墨绿长发、红框眼镜，神情从容。白色立领肩披仅覆盖人物左肩，叠在黑色贴身长衣外；青绿色半透明外摆从腰带垂至小腿，人物右腰的金环系着三根分离的红绳。她站在石质回廊中，身体轻转、脸朝镜头，右手轻扶镜腿，左臂自然下垂，腰间金环与绳结清楚可见。柔和天光从画面左侧照入，暖色室内光落在背后的门框；皮肤保留自然纹理，白色织物有细密织纹，黑色面料半哑光，薄纱透光，金属反射周围环境。脸、肩披连接处和腰饰清楚，背景适度虚化；保持实体假发、裁片、接缝与衣物重量的摄影质感。

**返修取决于实际偏差。**若整体已成立，仅肩披错到另一侧，可先编辑肩披并保护面部、姿态和其他服装；若因为姿态遮住腰饰，需在服装锁定范围内调整手臂或机位，而非再次加“细节丰富”。若身份、构图和层次一起失效，回到布局或参考，不能期望连续局部补丁救回错误基础。用户锁定全身时，应重排构图，不能把本例的到膝方案当作通用最优。

假设回传图仅肩披左右错误，编辑正文可写：

> 将原图白色肩披调整为仅覆盖人物自身左肩，保留立领，修正肩披的固定点、布褶与合理遮挡，右肩恢复黑色内层。保留人物面容、墨绿长发、红框眼镜、扶镜姿态、右腰金环与三根红绳，以及原有机位、裁切、回廊和光色；仅允许肩披改动涉及的接缝、遮挡与阴影作必要联动。

**参考能省掉什么。**真实任务已有准确服装参考时，用实际素材标识明确“只控制服装版本、色块、层叠与配件连接”，再写本次姿态、场地和光线；无需将参考里每条纹样抄成文字。文字仍须保留最容易错的非对称位置、用户指定改动与保护项。参考未绑定时，必须给足文字条件或标明待替换引用，不能交出依赖不存在图片的“完整提示词”。

成稿前做一次需求映射：独立条件能否在正文、实际参考职责或真实设置中找到归属；同一句是否只是在重复审美赞词。此检查用于发现遗漏与浪费，不默认输出参数表。以上示范没有实际出图，不能据此宣称细节已还原。

## 9. 结果诊断与返修

分别核对需求兑现、身份、数量/归属、空间、文字、媒介、材质和审美。漂亮不能抵消漏人、错字、商品换款；字段齐全不能证明好看。

主体或布局根本错误，重新设计/生成可能更合适；总体成立只差局部，优先编辑。提示误解、素材冲突、入口设置和生成偏差分别诊断。只改相关的一组因素，保留已成立部分；两轮同类失败后换机位、参考、方法或后期路线，不堆“更真实、更高级”。
