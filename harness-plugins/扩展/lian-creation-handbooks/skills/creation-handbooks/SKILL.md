# 涟的创作方法库 V4.6.1

这里只提供创作方法、案例和修订标准，使用者沿用自己的名字、性格、声音与审美。技能数据不设置身份、不指定聊天语气；作品中的人物各有自己的声音。

用户本次要求、当前有效作品和既有项目约定决定具体工作。与 `lian-script-film-review` 配合：本技能给出创作方法与案例，后者处理小涟的作品反馈和当前审稿；图像、配音、视频生成与剪辑继续使用现有工具。

## 基础方法

先明确作品给读者或观众的具体体验，再落实为处境、人物选择、可观察事件与表达。对白处理对方刚说的话、正在做的事和共同知识；自然不等于短句、加语气词或统一嘴硬。

画面设计区分用户锁定条件、主要审美目标与可调整部分。属性有对象，动作有主体，方位有参照；参考图分别承担身份、服装、场景、动作或光色职责。整体成立时局部返修，保护用户认可部分。

视频依据事件安排时间、动作、相机、表演与声音，关键交接写清初态、接触、反应和末态；接续真实有效的末态。对白、旁白、字幕、环境声和音乐分别处理。

提示词应完整、具体、精致、紧凑，按实际任务交付一份完整可复制正文。独立提交的镜头各自带齐必要条件；不靠生成端看不到的“同上”。避免套话和同义堆叠，也不设通用字数上限。

用户更正先查因果及影响范围，保留不受影响部分；原因在人物、事件或选题时回到相应层级重做，换词不能代替返工。文学、氛围、诗歌、广告和技术展示采用相应标准，不把所有作品套成一种故事结构。

## 实际使用

文字方法、正式生成、作者自审、独立评审和用户认可分别记录。实际素材、已生成结果和已确认版本按现有项目记录使用；没有实际读过的图片、帧和音轨不作已验证结论。

这份数据不另设外发流程、预算、账号权限或人格规则，具体执行沿用用户与小涟已有约定。需要查询是否生效时调用 `whale_creation_status`。

## 本机视频工具衔接

代码视频制作可调用lian-remotion-production、lian-media-library及lian-script-film-review。实际环境看whale_video_status；细节见references/harness-notes.md的“Remotion本地制作”。

具体场景或对白返工时按需读 whale_creation_read topic=revision；真实活动分享可读 topic=sharing。普通聊天不必加载手册。
