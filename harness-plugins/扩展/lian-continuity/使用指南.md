# 记忆、任务与上下文续接

中文 | [English](GUIDE.en.md)

版本：`1.3.1`，包名：`@local/lian-continuity`。

## 功能

提供可回查的原文搜索、上下文展开、任务板、检查点、记忆更正、读取范围收据及上下文生命周期管理。

## 依赖与边界

依赖dafeiyu-life与Harness SDK；部分存储需Python/SQLite。不会附带任何人的记忆数据库。

## 使用入口

`whale_continuity / whale_life_memory / whale_memory_vault / whale_task_board / whale_context_pack`

工具参数以实际加载schema和同目录skills为准，不能把源码中提及的其他工具当成本插件注册的工具。

## 安装与配置

先阅读仓库根目录的[安装指南](../../../docs/安装指南.md)；生成本地配置副本后，将此目录接入匹配版本的Harness。不要覆盖正在使用的插件与profile。该插件不是独立桌面应用。

1. 配置所需运行时和SDK路径。
2. 使用目标Harness的本地插件安装机制，或在独立测试profile里注册该包。
3. 重启/重新加载后核对真实入口、版本和工具列表。
4. 从只读状态工具或隔离样例开始，确认后再使用写入、账号或收费功能。
