# lian-continuity

小涟的本地连续性与任务续接扩展。数据放在 E:/LianHome/记忆/连续性档案，运行在现有 Harness desktop profile。

四个工具：whale_continuity（事件/完整性/备份）、whale_task_board（版本化任务/认领/产物）、whale_life_memory（自选记忆/纠错/收藏）、whale_context_pack（续接包/文本片段/用量）。一个按需技能 lian-continuity，另有只读任务与费用看板。

本机安装：固定Node执行install.mjs。它保留profile其他配置并先备份，加入本地dependency/junction及一条原生Loader条目；不重复加入bundle，以免同一id双重挂载。已接入的机器无需再装一遍。

数据库为SQLite WAL，stable key去重，任务使用版本检查与写者租约，纠错保留原文。备份为VACUUM INTO一致性副本。身份文件只观察留版本，不自动改写或回滚；本地哈希链不是绝对防篡改证明。

初始化只补录指定主会话，后续监听家目录会话。近期事件不复制全部聊天正文；重要内容由小涟主动保存，原始对话仍由Harness负责。公开知识继续使用现有ReMe，不默认将私密记忆同步到公开知识库。

费用按真实usage记录；已核对的Flash价格仅覆盖2026-10-24至10-31，未知模型或日期显示未知，不冒充供应商账单。跨峰谷边界时响应事件时间可能与请求开始时间不同。自动周期检查都是本地操作，日常运行不轮询模型；手动配置的维护交接与原生压缩会触发实际模型调用并产生费用，当前交接与压缩的临时开关已在验收后移除。

完整性检查、状态、备份和工具探测不调用模型。测试运行test.mjs，使用隔离临时资料，不写入真实私人记忆；原生验收结果在家目录安装验收。当前11项测试通过。

参考方法及来源在 E:/LianHome/工作室/成熟平台方法提炼与落地_20261026.md；代码为本机适配实现，没有复制闭源平台实现。原有对外操作约定、人格、账号规则、时段和预算不在此扩展里重设。
