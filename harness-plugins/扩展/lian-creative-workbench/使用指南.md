# 创作工作台

中文 | [English](GUIDE.en.md)

版本：`1.4.0`，包名：`@local/lian-creative-workbench`。

## 功能

把写作、代码动画、三维制作、设计和声音工具放到统一工作台，方便助手从构思进入不同创作工具。

## 适合什么场景

例如写好短片想法后，使用 Motion Canvas（代码矢量动画）、Blender（三维制作）或声音工具继续制作。对应软件和服务需自己安装，本插件不是这些软件或模型本体。

## 依赖与边界

按需配置外部软件、模型、MCP与运行时；不是自带模型的一体安装包。

## 使用入口

`whale_writing_workshop / whale_motion_canvas / whale_blender_studio / whale_voice / whale_song`

工具参数以实际加载schema和同目录skills为准，不能把源码中提及的其他工具当成本插件注册的工具。

## 安装与配置

先阅读仓库根目录的[安装指南](../../../docs/安装指南.md)；生成本地配置副本后，将此目录接入匹配版本的Harness。不要覆盖正在使用的插件与profile。该插件不是独立桌面应用。

1. 配置所需运行时和SDK路径。
2. 使用目标Harness的本地插件安装机制，或在独立测试profile里注册该包。
3. 重启/重新加载后核对真实入口、版本和工具列表。
4. 从只读状态工具或隔离样例开始，确认后再使用写入、账号或收费功能。
