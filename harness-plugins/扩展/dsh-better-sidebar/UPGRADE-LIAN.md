# 小涟侧栏修复 0.28.0-lian.1

此版本恢复会话工作区范围校验，并为侧栏删除和覆盖提供恢复记录。它只约束本插件受检入口，不是操作系统沙箱，也不代替其他插件、Shell、桌面和浏览器的权限控制。

## 行为变化

- 文件读写、媒体/HTML、观察、搜索直达路径以宿主已提交的会话目录为边界。客户端传入 cwd 不再建立权限；会话不存在或没有可信目录时拒绝请求。
- 检查绝对路径、相对路径、真实父目录和 Windows 目录联接。新目录尚不存在时也验证最近现存父目录。拒绝驱动器相对路径、设备命名空间、ADS 和 Windows 模糊文件名。
- 内部链接可以正常读取；指向工作区外部的链接不能被读取或穿透写入。删除/改名链接本身仍可使用，不触碰链接目标。
- 推断工作树、环境覆盖或 Git 工作树选择不能扩大原会话目录范围。需要访问另一个工程时，应先在宿主中明确切换会话工作目录。仅在子目录开启的会话若要操作整个 Git 仓库，应切换到仓库根。
- 目录预览不会通过外部链接探测目标目录，也不会从较大权限范围的缓存泄漏到较小范围。
- 删除改为移动到当前工作区的 .dsh-sidebar-recovery；编辑保存和上传覆盖之前复制旧版。保存失败不会偷偷改回永久删除。
- 恢复目录自带 .gitignore，默认文件列表与搜索排除它；系统压缩导出也排除恢复内容。可以通过恢复 API 或本地命令列出并恢复。
- 同一宿主进程中、相同真实工作区的侧栏修改串行执行。带旧 mtime 的编辑会被拒绝，避免两个同基线保存静默互相覆盖。

## 恢复

恢复工具只读取指定工作区，不启动 Harness，不请求模型。

    node scripts/recovery.mjs list "E:/指定的工作区"
    node scripts/recovery.mjs restore "E:/指定的工作区" "列表中的恢复ID"

恢复默认放回原位置，目标已经存在时拒绝覆盖。先另存或改名当前文件，再恢复需要的版本。也可调用已受会话认证保护的 fs.recovery.list 与 fs.recovery.restore API。尚未新增客户端恢复按钮；现有文件管理界面的删除动作会自动归档。

目录内容使用原子移动保留，普通文件旧版使用独立副本；恢复失败或状态不完整时记录仍保留，不自动清空。恢复数据会占磁盘空间，本版没有自动淘汰历史。目录移动仅在同一工作区卷内进行；挂载点、磁盘异常或跨卷失败会保留原件并报错，不退化为永久删除。

## 构建与验证

    node scripts/build-hardening.mjs
    node --test test/hardening.test.mjs
    node --check lib/index.js
    node --check lib/recovery.js

构建复用现有 esbuild，默认依赖目录为 E:/DSH/插件/扩展/node_modules，可用 SIDEBAR_DEPENDENCY_ROOT 指定。只重建 lib/index.js 与 lib/recovery.js，不清空已发布客户端包。依赖的宿主 file URL 保留原安装路径。

43 项 Windows 行为测试包括真实 junction、缺失父目录、特殊路径、目录预览缓存隔离、伪造 cwd、并发保存、删除与覆盖恢复、真实 tar 导出和构建后恢复 CLI。测试只使用本包 .test-build 下的合成文件。

## 已知边界

- 校验和实际系统调用之间仍存在同权限外部进程修改路径的竞态；跨进程、恶意 reparse point 置换和 OS 级隔离未在本补丁保证范围内。
- 非本插件的 Shell/文件工具及 Git 自身可运行的 hooks/过滤器不受这些 JavaScript 路径函数约束。Git checkout、discard 等继续遵循 Git 原有语义，不自动加入本次文件恢复区。
- 本次未在真实个人工作区做删除/恢复，没有启动或重启生产宿主。宿主装载、浏览器 UI 和授权的实际工程操作需要部署后的烟测。
- 已同步简体中文、繁体中文和英文删除提示为恢复存储。其他语种仍沿用旧提示；后续可补齐多语种并添加恢复面板。

上线前由主代理核对实际安装文件哈希没有改变，再复制批准的差异。回滚至少同时恢复 lib/index.js、源码与 package.json；已生成的恢复目录保留，不应随插件回滚删除。
