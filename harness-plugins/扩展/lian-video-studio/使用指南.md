# 视频项目、渲染与成片核对

中文 | [English](GUIDE.en.md)

版本：`1.5.2-lian.1`，包名：`@local/lian-video-studio`。

## 功能

用代码创建、预览和导出视频，并检查导出的成片；可把一段视频抽成带时间标记的画面宫格，再点回某一张原帧。

## 适合什么场景

例如先做十秒动画样片，预览并导出后检查字幕、音频或抽取关键画面。Remotion 是用 React 写视频画面的工具；FFmpeg 是处理媒体的程序，两者及相关环境需要另行准备。宫格是抽样，不等于看完每一帧。

## 依赖与边界

需要lian-video-runtime与FFmpeg；感知和声音功能需相应本地模型服务。抽样不等于逐帧观看。

## 使用入口

`whale_video_project / whale_video_render / whale_film_evidence / whale_creative_review`

工具参数以实际加载schema和同目录skills为准，不能把源码中提及的其他工具当成本插件注册的工具。

## 安装与配置

先阅读仓库根目录的[安装指南](../../../docs/安装指南.md)；生成本地配置副本后，将此目录接入匹配版本的Harness。不要覆盖正在使用的插件与profile。该插件不是独立桌面应用。

1. 配置所需运行时和SDK路径。
2. 使用目标Harness的本地插件安装机制，或在独立测试profile里注册该包。
3. 重启/重新加载后核对真实入口、版本和工具列表。
4. 从只读状态工具或隔离样例开始，确认后再使用写入、账号或收费功能。
