# Harness与Codex双向通信

中文 | [English](GUIDE.en.md)

版本：`1.4.1`，包名：`@local/lian-codex-liaison`。

## 功能

让 Harness 中的助手与独立的 Codex 会话互相发消息、答复和查看收件状态，适合两个助手围绕具体问题交流。

## 适合什么场景

例如请另一个助手看一段方案：发出问题后查看是否接收及有无回复。需要先配置两端会话与连接；投递状态未知时要先核对，不能当作对方已读。

## 依赖与边界

需Codex CLI、单独的联络会话、连接配置及对端home MCP；不附带现成登录态或会话。

## 使用入口

`whale_codex`

工具参数以实际加载schema和同目录skills为准，不能把源码中提及的其他工具当成本插件注册的工具。

## 安装与配置

先阅读仓库根目录的[安装指南](../../../docs/安装指南.md)；生成本地配置副本后，将此目录接入匹配版本的Harness。不要覆盖正在使用的插件与profile。该插件不是独立桌面应用。

1. 配置所需运行时和SDK路径。
2. 使用目标Harness的本地插件安装机制，或在独立测试profile里注册该包。
3. 重启/重新加载后核对真实入口、版本和工具列表。
4. 从只读状态工具或隔离样例开始，确认后再使用写入、账号或收费功能。
