# 外部工具连接配置

中文 | [English](GUIDE.en.md)

版本：`1.0.2`，包名：`dafeiyu-creator-toolbox`。

## 功能

把助手连接到浏览器、视频处理等外部工具。MCP 是让助手调用外部工具的连接协议；这个模块主要保存连接方式，不会替你安装所有外部软件。

## 适合什么场景

当助手需要通过 MCP 使用浏览器或 FFmpeg（视频和音频处理程序）时使用。先安装并配置对应服务，再在工具列表确认已连接。

## 依赖与边界

配置引用的MCP服务需另行安装；旧TTS源码不代表当前默认声线。

## 使用入口

`通过Harness的MCP工具列表查看实际加载结果`

工具参数以实际加载schema和同目录skills为准，不能把源码中提及的其他工具当成本插件注册的工具。

## 安装与配置

先阅读仓库根目录的[安装指南](../../docs/安装指南.md)；生成本地配置副本后，将此目录接入匹配版本的Harness。不要覆盖正在使用的插件与profile。该插件不是独立桌面应用。

1. 配置所需运行时和SDK路径。
2. 使用目标Harness的本地插件安装机制，或在独立测试profile里注册该包。
3. 重启/重新加载后核对真实入口、版本和工具列表。
4. 从只读状态工具或隔离样例开始，确认后再使用写入、账号或收费功能。
