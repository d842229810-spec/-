# Known limitations

[中文](已知限制.md) | English

1. This is a 2026-10-30 Windows / Harness 0.2.1-rc.3 source snapshot, not a cross-platform one-click installer.
2. Example paths, SDK layout, workspaces, sessions, accounts and external software need local configuration. configure.mjs only generates a text-substituted copy.
3. Some historical integration entry files remain. package.json selects the packaged entry, while actual profiles may need their own compatible registration. Do not load every historical entry simultaneously.
4. Retrieval receipts describe returned coverage, not comprehension. Overview sampling is not full continuous viewing.
5. Budget protection covers integrated life calls, not every plugin API call or QQ expense.
6. Desktop actions, social sending, autonomous activity and model generation can have real side effects. Packaging did not start them or authorize them in a new environment.
7. Path checks and application-level locks are not an operating-system sandbox.
8. Original README test counts are historical local records. The packaging checks did not repeat long-running stability, all accounts/models or another-machine acceptance. See RELEASE-CHECKS.en.md.
9. A public repository does not imply a single license for all files. Existing third-party terms remain; unspecified files are not automatically MIT-licensed.
