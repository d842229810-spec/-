## Reliable memory

Continuity1.5.2 commits note content, sources, corrections and request receipts consistently. Archive and index status remain separate and can be repaired. Reusing the same requestKey retries one operation without creating a duplicate.

Evidence supports current-value and history lookup. A verified claim requires a basis, what was verified, when and a source reference; it is a recorded claim, not automatic truth detection. Integrity checks detect changes to registered material. Recovery previews a version before an explicit selection.

- Status: whale_life_memory({action:"health"}).
- Evidence: whale_life_memory({action:"evidenceGet",noteId:"your-note-id"}).
- History: whale_life_memory({action:"evidenceHistory",noteId:"your-note-id",limit:10}).
- Use repair for failed archival; follow the live schema for preview-first recovery rather than overwriting an active store.

## Video receipts and local evidence

Bilibili1.5.0 separates acquisitionStatus from coverageStatus and reading. Empty ASR remains unknown. Default responses have a whole-response budget while complete evidence stays on disk.

Read with whale_bili_perceive({url:"public-video-url",mode:"full"}). Retrieve local cues with whale_bili_evidence({report:receipt.cache.artifact,sha256:receipt.cache.sha256,field:"segments",start:30,end:60}). Follow nextOffset for text pages, then selection.nextSegmentOffset for cue pages. Retrieved images still need inspection.

whale_learning_sources exposes status/search/get. The public learning-sources/manifest.json starts empty. Add your own summaries and JSON artifact SHA256 values using the version1 schema in source-catalog.mjs. get defaults to summary; body/review explicitly expand content. A changed artifact returns stale. Searching metadata does not mean reading a document.

## GPU-first offline transcription

lian-shared/local_asr_runtime.py is shared by local-asr/transcribe.py. Auto mode prefers CUDA/float16 and falls back to CPU/int8 with the device, processed range and fallbackReason reported. It reuses installed model/dependencies without automatic model downloads. Existing CLI arguments remain supported; --device accepts auto/cpu/cuda, and explicitly requested CUDA reports an error rather than silently falling back.

Generate a configured copy first, then provide faster-whisper-medium, Python and appropriate GPU libraries. CPU operation remains available; measure speed on your machine.

## Snapshot and sources

The same15 components now include current source versions plus public lian-shared adapters. catalog.json describes the snapshot, not universal runtime compatibility. Existing MIT-derived components retain the upstream explanations in [UPSTREAM](UPSTREAM.en.md).

Bounded receipts and on-demand source expansion were informed by public projects including dsh-bili-pond, dsh-bili-subagent and dsh-at-file. New receipt/evidence/catalog code was independently implemented, without copying code from the newly reviewed repositories.
