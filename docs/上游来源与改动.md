# 上游来源与本地改进

[English](UPSTREAM.en.md)

以下逐项说明本合集明确使用的第三方项目。原项目作者及许可证以对应上游和随附许可证为准；本地版本是在原项目或代码基础上的适配与改进，不声称整套由本仓库从零编写。

## 更好用的侧栏：基于原项目修改

- 上游：[omdsh-dev/DSH-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar)，MIT；本地版本 0.28.0-lian.1。[随附原许可证](../harness-plugins/扩展/dsh-better-sidebar/LICENSE)。
- 本地改进：按会话工作区检查文件路径与链接；删除及覆盖前保留恢复记录；串行化同工作区修改，并拒绝基于旧修改时间的保存。
- 这是应用层保护，不是操作系统沙箱。具体行为与边界见[侧栏改进说明](../harness-plugins/扩展/dsh-better-sidebar/UPGRADE-LIAN.md)。

## QQ桥：基于原项目修改

- 上游：[Yuuyuko-uu/dsh-qq-bridge](https://github.com/Yuuyuko-uu/dsh-qq-bridge)，MIT；本地版本 0.6.2-lian.1。[随附原许可证](../harness-plugins/扩展/dsh-qq-bridge/LICENSE)。
- 本地适配包括按 @、称呼或回复进行群消息寻址，区分群成员与已绑定用户的请求来源，记录消息处理回执，以及语音收发和跟进适配。参见插件内的 lib/lian-groups.mjs、lib/lian-receipts.mjs 和语音模块。

## 自主学习：复用B站接口代码

- 上游：[moxingovo/dsh-bilibili](https://github.com/moxingovo/dsh-bilibili) 0.2.4，commit 923d884698bb7b3b9de8a651de970c801bf10d0d，MIT。复用 provider、types、wbi 三个文件；[原许可证](../harness-plugins/dafeiyu-life/vendor/moxingovo-bilibili/LICENSE)和[详细来源](../harness-plugins/dafeiyu-life/vendor/moxingovo-bilibili/UPSTREAM.md)随附。
- 本地让 provider 接受注入的 fetch，接入现有受限网络传输和接口兼容处理；自主活动、预算预占与结算是本地模块自己的集成与后续可靠性改进，并非上游整个插件。
