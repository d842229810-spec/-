# 依赖与运行时

## 基础依赖

Harness宿主提供Cordis、dsh-tools、dsh-llm等SDK。多个插件按桌面应用SDK布局动态导入，不是装一个同名npm包就必然兼容。请先确认目标应用版本与SDK路径。

## 仓库附带的适配源码

| 目录 | 用途 | 还需准备 |
| --- | --- | --- |
| lian-video-runtime | Remotion渲染、原子输出与项目模板 | Node依赖、浏览器/渲染环境、FFmpeg |
| sensory-runtime | GPU资源租约、声音监测适配 | 对应音频/视觉服务 |
| video-perception-runtime | 视频序列准备、跟踪与视觉客户端 | 本地视觉服务与模型 |
| audio-understanding-runtime | 本地音频理解客户端 | 支持音频的本地模型服务 |
| film-study-runtime | 影片分析脚本 | Python、OpenCV等依赖 |
| local-asr | 本地转写与模型准备脚本 | requirements.txt及ASR模型 |
| voice-design-runtime / index-tts-runtime | 本地声音客户端与适配 | 上游语音项目、模型与虚拟环境 |
| music-runtime | 本地音乐客户端与适配 | 上游音乐项目、权重与环境 |
| motion-canvas-runtime | 代码矢量动画工作区 | 对应npm依赖、FFmpeg |
| blender-runtime | Blender启动、MCP代理与脚本 | Blender、Python/MCP依赖、上游服务 |
| opendesign-runtime | OpenDesign服务解析与启动适配 | OpenDesign本体与MCP |
| shared-mcp-runtime | MCP依赖清单 | 重新安装声明的依赖 |

这些目录是适配脚本，不是已安装的完整软件。为了避免上传体积庞大的第三方工程、私人配置和模型缓存，没有收录upstream/source/source-http、虚拟环境、模型权重或生成作品。请按脚本引用及上游说明分别准备。

## 按需求选配

只需要记忆与任务板，可先配置life、continuity；ReMe桥为可选。需要代码视频时增加video-studio、lian-video-runtime和FFmpeg。需要实际视频内容分析时再加视频感知、ASR及音频服务。需要QQ时单独准备OneBot；不需要一次启用全部插件。

## 未打包的已有第三方插件

ReMe、BrowserSkill、平台后端、模型服务等应从各自上游安装。本合集不把未修改的第三方组件计为自己制作的插件。
