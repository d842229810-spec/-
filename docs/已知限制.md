# 已知限制

1. 本合集是2026-10-30的源码快照，主要针对Windows / Harness 0.2.1-rc.3。不是完成跨平台封装的一键安装产品。
2. 本机绝对路径已改为示例，目标SDK、Python、媒体软件、工作区、会话及账号需要配置；内置configure只做文本路径副本，不自动完成系统安装或所有协议适配。
3. 一些模块是本地历史集成，源码包含多版入口。package.json指向当前入口；单独接入时还应核对本机profile。保留历史源码不表示各入口应同时加载。
4. 原文搜索、读取收据证明返回了哪些范围，不证明模型理解；概览抽帧不能证明完整连续观看。
5. 预算只覆盖life已接入的调用；其他插件直连API、群聊费用等不能因此被统一约束。
6. 桌面操作、QQ发送、自动活动和生成模型涉及真实外部动作。上传源码时未启动这些功能，也没有把它们自动授权给新的安装环境。
7. 侧栏路径检查、进程锁与应用层策略不是操作系统安全沙箱。
8. 原始README中的测试数字是历史本机记录；此次发布副本的检查范围见发布检查.md。没有新做长周期稳定性、全部外部账号、全部模型或另一台电脑的验收。
9. 源码公开不意味着所有文件都获同一种再分发许可。第三方许可保留；未明确授权文件以其现有声明为准。
