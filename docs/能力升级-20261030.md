# 本次能力更新（2026-10-30）

[English](CAPABILITY-UPGRADE-20261030.en.md)

本次继续更新原有15个插件/配置模块。没有额外增加必须常驻的模型服务。

## 用起来有什么变化

- 找工具：lian-extension-bridge 1.1.0 新增 whale_capability_find，按目的返回少量工具、用法和当前注册状态。问“这一秒长什么样”会优先返回精确取帧入口。注册状态不保证所有外部依赖已就绪。
- 找记忆：lian-continuity 1.4.0 增加常见同义问法和命中原文的位置，保留来源、纠正关系及前台读取收据。搜索预览与完整读取仍然分开。
- 接任务：whale_task_board 保存产物版本。普通进度更新保留原证据哈希，verify 发现文件变化、缺失及尚未确认的外部操作。跨重启可能重试的写入使用稳定 requestKey 和 expectedVersion（当前记录版本号）。
- 做代码视频：project 关联输入与镜头，plan 判断受影响的镜头，render 登记实际输出。工具记录和规划；Remotion、Motion Canvas、Blender 等现有渲染器实际执行。全局声音和转场仍可能需要整片合成。
- 改作品：feedback 绑定旧产物、新产物和具体依据；accepted 表示接受建议，resolved 还需要修改依据与登记过的新版。handoff 生成选定摘要，不自动发送。
- 看费用：operation 记录操作和回执，costs 按币种分别列出实价、估算和未知费用。只覆盖已登记操作，未知不算零，不代替全局预算拦截。
- 创作方法：lian-creation-handbooks 4.7.0 新增 revision（场景与对白修订）与 sharing（真实日常），按需读取。它们是写作参考，不是固定人格或自动审美评分。

任务与代码视频的字段例子见[任务板操作](任务板操作.md)。

## 通信时间与QQ配置

lian-codex-liaison 1.5.1 默认采用北京时间空闲通信策略：周一至周五，排除已核实中国节假日，09:00–12:00和14:00–18:00暂停模型通信；其他时间、周末和节假日允许。发起、执行排队请求和回复转交都检查时间。2026年日历及来源在对应模块 holidays.mjs；以后年份未知的工作日采用较严格的普通工作日窗口。此策略是本项目的默认设置，不是所有模型服务商的统一价格规则。

QQ桥的双方互聊规则需要在该插件的Cordis配置中明确指定对方QQ与群。示例仅为占位号码：

~~~yaml
- id: qq-bridge
  config:
    peerCommunication:
      peerQQ: '100000002'
      groups: ['100000004']
~~~

配置后，所列群中该发送者的消息在高峰不会唤醒模型；已绑定用户本人的消息沿用原有处理。此项只覆盖该已配置入口，不是所有群成员、所有QQ后端的全局计费规则。公开仓库不包含实际账号绑定或聊天记录。

## 版本与依赖

修正了6个模块的精确 rc.3 限制，明确允许 rc.3 或 rc.5：dafeiyu-life、dafeiyu-toolbox、bili-perception、lian-extension-bridge、lian-creative-workbench、lian-video-studio。没有绕过宿主兼容检查。新增任务记录继续使用宿主提供的 Node SQLite 能力；本机 rc.5 环境中已实际加载和调用。其他机器仍需按[安装指南](安装指南.md)配置路径、SDK与外部依赖。

本轮软件在本机做过隔离样例和实际工具调用核验：任务能发现文件变化，导航与创作资料可调用；代码视频样例只重渲变化镜头并成功导出。QQ时段逻辑用假消息验证，没有为了发布向真实账号发送测试内容。发布副本另检查语法、占位配置及文件完整性。这些记录不等于所有机器、全部模型和每种作品均已通过验收。

侧栏、QQ桥和部分B站功能继续保留原项目来源与许可证，见[上游来源与改动](上游来源与改动.md)。

联络回传补修：1.5.1按消息ID和完成回合捕获正常最终正文并主动通知固定联络会话；同时隔离QQ回发。混合用户输入、中断或空正文不自动转发。手动回信沿用旧入口且不重复发送。

导航1.1.1明确区分：state只描述注册情况，implementationState=not-verified表示未验收工具实现版本；evidence指出注册信息来自当前进程工具表，不能据此证明外部依赖或磁盘代码已更新。

工具数量只说明入口数量，不表示每条功能都做过完整流程验收。自动回信只允许已核对的 lian-memory-bootstrap 固定续接提示同回合出现；其他额外输入来源仍保留待核对状态。
