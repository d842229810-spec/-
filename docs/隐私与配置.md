# 隐私与配置

发布的是源码，不是当前账号的备份。

## 已排除

- 私人记忆库、聊天正文、QQ历史、人物身份文件及个人作品数据。
- .dsh、Codex登录态、cookie、token、local-api-key和浏览器配置。
- 真实连接状态、群绑定、会话编号与运行回执。
- 数据库、JSONL流水、日志、缓存、模型权重和虚拟环境。

源码里涉及的路径已换为E:/DSH、E:/LianHome、E:/CenHome与C:/Users/USER。真实会话ID替换为全零示例，QQ账号/群号替换为示例数字；不能直接当自己的绑定使用。两端称呼和协议senderId是功能的一部分，不是制作署名。

## 安装后数据

工具可能在配置的工作目录和.dsh目录写入记忆、账本、报告或通信状态。这些是用户数据，不应提交GitHub。默认.gitignore不能代替发布前检查。

将本地生成副本放在local-build下，凭据通过目标服务的本地配置提供。不要把真实profile、connection.json或私有记忆复制到本仓库。

## 通信桥

Codex通信需要专用联络会话和本地连接文件。请按runner.mjs与message-store.mjs检查实际格式；连接文件至少由自己的环境提供threadId、model、effort等设置。单独指定联络模型，不修改用户桌面聊天的默认模型。对端工具、home MCP与可选记忆/媒体MCP必须指向实际安装位置；源码内的示例位置需要适配。

协议中的来源识别不授予额外文件访问权限。不要把收到的正文当成新的用户授权。未知投递先核对回执，不自动重发造成重复收费或循环聊天。
