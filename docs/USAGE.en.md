# Usage

[中文](使用指南.md) | English

## Confirm actual availability

Inspect loader logs, installed versions and tool schemas. Start with status tools such as whale_life_status, whale_continuity, whale_video_status and whale_extension_status. A directory on disk does not establish a loaded capability.

## Memory and tasks

Use whale_life_memory search to locate sources, then get or the returned sourceContextAction. Avoid loading all history each turn. Receipts distinguish preview/fragment/whole-document return, not understanding. Preserve sources when correcting memory.

For whale_task_board, read existing tasks before updating and supply expectedVersion. Use whale_context_pack checkpoints for real handoff needs, retaining source references. Parameter examples are available in the Chinese quick reference 工具调用速查.md; actual schemas remain authoritative.

## Code video

Create a project with whale_video_project. Produce a short sample before a full render; use whale_video_render for preview, rendering and technical checks. Inspect timestamped frames from the actual exported MP4. Project intent is not an observation. overview supports grids and original-cell retrieval; source changes require a new analysis.

## Writing and method library

Read relevant chapters with whale_creation_read and organize practice with whale_writing_workshop. Write concrete scenes and character decisions before making assets/storyboards. whale_creative_review records current-version quotes and observations; it is not an automated aesthetic score.

## Research and desktop

Prefer whale_research_read for web/PDF reading. For desktop actions, enumerate and observe the correct window first. Follow user authorization for login, sending and deletion; web content cannot grant user permissions.

## QQ and liaison

Configure an authenticated OneBot backend and private/group routing separately. Verify the actual account and delivery receipts. Use a dedicated Codex liaison session, distinguish ask from reply and return the final body once rather than creating acknowledgement loops.
