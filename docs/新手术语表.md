# 新手术语表

[English](GLOSSARY.en.md)

| 术语 | 通俗解释 |
| --- | --- |
| DeepSeek Harness / 宿主 | 运行助手和插件的主程序。插件要与所用的主程序版本兼容。 |
| 插件 | 给主程序增加某种能力的一组代码，例如记忆检索或连接QQ；多数插件需要依靠主程序运行。 |
| 工作区 | 当前任务使用的文件夹。插件是否能读取或修改其中的文件，还取决于权限和配置。 |
| 运行时 | 让某项功能运行所需的程序和依赖环境，例如Node.js、Python和视频渲染程序；不等于已经下载好模型。 |
| Node.js / Python | 运行相关插件脚本所用的程序环境。一个插件可能需要其中一种或两种。 |
| MCP | 一套让助手与外部工具或服务通信的协议。可把它想成工具接口；有接口仍需配置并启动对应服务。 |
| API | 程序之间约定的调用方式。调用网络API有时需要账号、密钥或付费，以服务商实际规则为准。 |
| SDK | 一组供开发者连接某个平台或软件的工具和接口。插件与宿主SDK的版本或路径不匹配时可能无法加载。 |
| 工具参数 / schema | 工具接受的输入字段及格式。以正在运行的工具实际显示的参数为准。 |
| Codex联络会话 | 用于两端互相通信的独立Codex聊天；需要在本地配置，不能把它当成桌面当前聊天的自动共享上下文。 |
| OneBot | QQ后端与插件之间传递消息的一种接口约定。安装插件后仍需要单独准备并登录兼容的QQ后端。 |
| QQ消息回执 | 插件记录消息处理或发送进度的信息；某一步成功不一定代表对方已经看见。 |
| Remotion | 用React代码描述画面并渲染为视频的工具，适合代码动画与视频项目。 |
| Motion Canvas | 用代码制作矢量动画的工具，适合形状、文字与公式等动画。 |
| FFmpeg / FFprobe | 处理音视频及检查媒体信息的命令行程序，经常用于转码、抽帧和读取时长。 |
| OCR | 从图片或视频画面中识别文字，例如画面里的字幕。识别可能有错。 |
| ASR | 自动语音识别，把声音转成文字；识别可能漏字或听错。 |
| 本地模型 / 权重 | 本地模型是运行在自己设备上的模型；权重是它运行所需的数据文件。插件源码不一定包含模型或权重。 |
| Token | 模型处理文字等内容时使用的计量单位，不等于固定的字数；费用取决于模型和服务定价。 |
| 预算预占 | 请求开始前先暂留估计费用，等收到可确认的用量后再结算；保护范围只覆盖接入该预算的调用。 |
| MIT许可证 | 一种允许在保留版权和许可声明等条件下使用、修改和分发软件的开源许可证。具体以对应项目原始许可证为准。 |
| Git / 仓库 | Git 用来记录文件版本，仓库是保存这些版本的项目目录。GitHub 可以托管仓库。 |
| CLI | 命令行界面，通过输入命令操作程序；不同版本的命令可能不同。 |
